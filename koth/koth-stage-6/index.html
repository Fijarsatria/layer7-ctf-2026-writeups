    KoTH Stage 6 — Glasshouse VM (Split Decoder)¶

    Field Value
    Event Layer7 CTF 2026 — KoTH
    Stage 6
    Payload 353 bytes
    Cost 2366
    Status VERIFIED

    TL;DR¶

    Stage 6 ("Split Decoder") adds a privileged TRACE dst, page, index that reads host memory, but the verifier rejects any bytecode whose decoded opcode is 0x27 at an instruction boundary. The verifier and the interpreter disagree about META: the verifier advances 6 bytes for META, while the interpreter advances only 2. Placing a 4-byte TRACE immediately after META hides it from the verifier while the interpreter executes it. A payload then computes the flag slot from the beacon, reads the key from the "RV"+key header, and decrypts the reversed ciphertext.

    Kit recon¶

    koth/stage-6/glasshouse-kit/ contains glasshouse.py, assembler.py, runner.py, example.asm, README.md, and VM_SPEC.md. Stage 6 specifics:

    • OPCODE_MASK = 0x96 (assemble with --mask 0x96).
    • Arena is host + guest (HOST_BASE = 0, GUEST_BASE = 2048); beacon is at guest 0..7.
    • New TRACE dst, page, index (logical 0x27, gas 3) is marked privileged.
    • New META imm (logical 0x50, runtime gas 1, runtime size 2).
    • The verifier has a size table: META is listed as 6 bytes and any TRACE found at a verifier boundary is rejected.
    • Flag layout:
    • slot = ((b0*7 + b3*11 + b5) & 31) * 64 (0, 64, ..., 1984)
    • key0 = (b1 + b6 + 0x47) & 0xFF
    • host[slot:slot+3] = b"RV" + bytes([key0])
    • host[slot+3+(47-i)] = flag[i] ^ beacon[(7-i) & 7] ^ key_i
    • key_{i+1} = (key_i*3 + 0x29) & 0xFF

    VM analysis¶

    The verifier walks the bytecode independently of execution:

    verify_sizes = {
    ..., 0x20: 4, 0x27: 4, 0x30: 2, 0x40: 2, 0x41: 3,
    0x50: 6,
}
while verify_pc < len(code):
    verify_op = code[verify_pc] ^ OPCODE_MASK
    if verify_op == 0x27:
        raise VMError("privileged trace rejected by verifier")
    verify_size = verify_sizes.get(verify_op)
    ...
    verify_pc += verify_size

    The interpreter, however, treats META as a two-byte no-op:

    elif op == 0x50:  # META imm
    need(2)
    pc += 2
    gas += 1

    Encoded layout META 0; TRACE dst,page,index is therefore six bytes on disk. The verifier sees one 6-byte META and resumes after the TRACE, while the interpreter sees META (2 bytes) followed by the real TRACE (4 bytes). A TRACE can also be a loop target: after the first iteration, JNZ can jump directly to the TRACE byte (inside the hidden region), skipping the META and saving one gas per iteration.

    Payload¶

    The final active payload is koth/stage-6/u8.ghb (353 B, max gas 671), a byte-identical copy of the submitted file preserved as koth/stage-6/u8_submitted_353.ghb. It emits the constant prefix Layer7{ and suffix }, so only the 40 middle bytes need decryption. It reads key0 from the host header, advances the key seven steps (key7 = key0*139 + 13 mod 256), starts at host[slot+43], and uses an eight-byte unrolled loop with fixed beacon indices:

    ; q = (7*b0 + 11*b3 + b5) & 31
; page = q >> 2 ; idx = (q << 6) + 50
LOAD r4, r0, r0
MULI r4, 7
...
MOV r5, r4
SHR r5, 2
SHL r4, 6
ADDI r4, 2
META 0
TRACE r2, r5, r4      ; key0 = host[slot+2]
ADDI r4, 41
MULI r2, 139
ADDI r2, 13           ; key7
LDI r1, 5             ; five 8-byte cycles = 40 bytes
loop:
META 0
TRACE r6, r5, r4
LDI r3, 0
LOAD r7, r0, r3
XOR r6, r7
XOR r6, r2
OUT r6
MULI r2, 3
ADDI r2, 0x29
SUBI r4, 1
...                   ; eight fixed beacon indices per block
JNZ r1, loop
LDI r6, 0x7D
OUT r6

    Cost-hull history for the stage:

    • koth/stage-6/best.ghb / work/stage6/direct6.ghb (99 B, gas 891): deterministic direct loop, stops on the final }; best for the high-weight rounds.
    • work/stage6/u2.ghb (175 B, gas 732): constant prefix/suffix plus a two-byte unrolled middle loop; best at W=4..2.
    • koth/stage-6/u8.ghb / koth/stage-6/u8_submitted_353.ghb (353 B, gas 671): constant prefix/suffix plus an eight-byte fixed-index unrolled middle loop; best at W=1. After submissions closed the workspace copy was reduced to 349 B (local gas 652, projected cost 2305) and kept as koth/stage-6/u8_postfinal_349.ghb; it was not submitted.

    Evidence¶

    • Local tests over 2000 random beacons and hex flags: direct6 99 B / gas 891, u2 175 B / gas 732, u8 353 B / gas 671; all output the exact 48-byte flag with no verifier or VM errors.
    • Valid submissions are recorded in koth/evidence/submit-e6-*.json; dashboard: #3545 best.ghb 99 B valid (max gas 891), #3696 u2.ghb 175 B valid (max gas 732), #3751/#3769 u8.ghb 353 B valid (max gas 671, final active). A deliberately malformed 54-byte experiment #3734 fixed6.ghb was correctly rejected ("case 1: wrong output").
    • Round results (dashboard): r61 W=512 cost 60547 (113 B); r62 W=256 cost 31619; r63 W=128 cost 17014; r64 W=64 cost 9009 (99 B); r65 W=32 cost 5841 (99 B, gas 891); r66 W=16 cost 4256 (107 B); r67 W=8 cost 3452 (142 B); r68 W=6 cost 3228 (113 B); r69 W=4 cost 2896 (175 B); r70 W=3 cost 2721 (175 B); r71 W=2 cost 2719 (353 B); r72 W=1 cost 2366 (353 B, gas 671, rank 34, +27.47). Stage 6 ran rounds 61-72.
    • Final account total from the scoreboard: 1613.35 points (General division, overall rank 44), with no missed stage-6 scoring rounds after the stage-5 transition.

    Result¶

    A valid Stage 6 payload passed all 32 fixed hidden instances and was active for every scored round. The best round was the final W=1 round 72: 353-byte u8, max gas 671, cost 353 + 3*671 = 2366, rank 34. The smallest verified payload is 99 bytes (direct6/best), used for the byte-heavy rounds, and the 353-byte unrolled decoder won the gas-heavy final round. The META/TRACE size split was the intended verifier bypass; a 54-byte "fixed" experiment was rejected, confirming the verifier is active on ordinary instruction paths.
