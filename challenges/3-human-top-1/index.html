    human top 1 — analysis report¶

    Status: the flag was not recovered. This document records the full reconstruction, every candidate that was derived, and the platform responses. The challenge had 0 solves on the scoreboard at the time of writing.

    TL;DR¶

    human top 1 is a layered puzzle. The attachment is a WebP image with a C2PA manifest from Anthropic Files and, more importantly, plaintext appended after the RIFF container:

    x = f * 2 + 0 * 4
f = f + 312452345234523345634564523452345
prefer imaginary root

    The description points at Roblox usernames (jonnybones, tpwnd, ir, Linear Circle, X) and the equation 20250928 - 500 = X. The first letters I, L, X are Roman numerals (1 * 50 * 10 = 500), which explains the 500 and gives X = 20250428.

    Two families of solutions were derived and tested:

    1. Roblox OSINT flavour: user IDs of ImaginaryRoot, LinearCircle / linear_circle, and humantop1 (the title read as a username), multiplied and base64-encoded.
    2. Hidden LFSR / GF(2) flavour: the appended number is a degree-107 feedback polynomial. Over GF(2) it factors as (x+1) · f17 · f89; the “imaginary root” is the degree-89 irreducible factor. Several values from this polynomial were tested.

    No submitted candidate was accepted ({"correct": false} for all of them). The most likely conclusion is that the final step uses a different numeric value/encoding than the ones derivable from the public clues, or that part of the puzzle was distributed out-of-band (Discord/ticket), as with challenge 13.

    Recon¶

    Attachment¶

    • for_user.zip (19,485 bytes, SHA-256 8236bf8a91a8fdb1dd0d5af8d36db78ce31ec6915327b88c6877964ee6275890)
    • contains one file: hehehe.png (23,527 bytes, SHA-256 5ccbfda9aaefa969bc07a19d7de78e3b21358b64ff46626c029d948b8635a22c)
    • the “png” is actually a WebP, 352×352, VP8, with a C2PA RIFF chunk.
    • exiftool reports Anthropic Files / Claude C2PA actions (c2pa.opened, com.anthropic.claude.provided), i.e. the image was produced or edited by an LLM.

    The appended plaintext¶

    The bytes after the RIFF payload (offset 0x5b94) are not covered by the C2PA signature:

    00005b94: 0a78 203d 2066 202a 2032 202b 2030 202a  .x = f * 2 + 0 *
00005ba4: 2034 0a66 203d 2066 202b 2033 3132 3435   4.f = f + 31245
...
00005bd4: 6665 7220 696d 6167 696e 6172 7920 726f  fer imaginary ro
00005be4: 6f74 0a                                  ot.

    So the real payload is:

    x = f * 2 + 0 * 4
f = f + 312452345234523345634564523452345
prefer imaginary root

    The number C = 312452345234523345634564523452345 has 33 decimal digits / 108 bits. Its integer factorisation is

    C = 5 · 71 · 1867 · 471423380484656933446841017

    and, as a polynomial over GF(2), it factors as

    C(x) = (x + 1) · f17(x) · f89(x)

    with f17 = 17-bit integer 174297 and f89 = 27-decimal-digit integer 686419102451932465175900639. The product of the three factors reproduces C exactly in GF(2)[x].

    Analysis¶

    Path A — Roblox user-id product¶

    Assume the three factors are the Roblox user ids of the accounts named by the hidden text, the formula and the title:

    • ir → ImaginaryRoot (221000549), confirmed by “prefer imaginary root”
    • Linear Circle → LinearCircle (89104053) or linear_circle (7628518636)
    • X → humantop1 (2646336636, the title read as a username) or 20250428

    For base64encode(str(product).encode()) the flag lengths are:

    factors product digits flag length
    ImaginaryRoot × LinearCircle × 20250428 24 40
    ImaginaryRoot × linear_circle × 20250428 26 44
    ImaginaryRoot × LinearCircle × humantop1 26 44
    ImaginaryRoot × linear_circle × humantop1 28 48

    The “at least 43 characters” hint rules out the 24-digit / 40-character combination. The 26- and 28-digit combinations were all tested; none was accepted.

    Path B — hidden GF(2) / LFSR¶

    The appended code is naturally read in GF(2) polynomial arithmetic:

    • f * 2 is a left shift (f << 1), f + C is XOR with the feedback polynomial C.
    • “prefer imaginary root” points at the roots of C that do not lie in GF(2), i.e. the irreducible factors f17 and f89.

    Values derived from C:

    • C itself → 33 digits → flag 52
    • C / (x+1) = f17 · f89 → 33 digits → flag 52 (tested, rejected)
    • f17 → 6 digits → flag 16 (too short)
    • f89 → 27 digits → flag 44 (tested, rejected)
    • 2^X mod C → 31 digits → flag 52 (tested by the watcher, rejected)
    • 2^X mod f89, X^X mod f89, 2^X mod f17, ... → 25–27 digits → flags 44

    The GF(2) factorisation is too exact to be accidental, but none of the straightforward factor/state encodings was accepted.

    Path C — Roblox + Wikipedia hybrid¶

    The official hint 2 says “refer to the wiki”. A hybrid reading is:

    • ir = Roblox ImaginaryRoot user id (221000549)
    • Linear Circle = Wikipedia article “Line–circle intersection” (latest revision id 1165429069)
    • X = 20250428 (Wikipedia page id, from the equation)

    This product is 25 digits → flag length 44. It was tested and rejected.

    Pure-Wikipedia readings (using Imaginary root → Complex number revision id 1385633439, Circle/Line–circle intersection revision ids and 20250428) also give 44–48-character candidates:

    • Layer7{MzI3MDE1NTUzMDY5ODMyMjcxMDExMzg1NDg=} (Complex number revid × Line–circle intersection revid × 20250428) — tested, rejected
    • Layer7{Mjg5MTI1NzA3MDcwNTkxNDI1Njc4ODkwNDA=} (Ir revid × Line–circle intersection revid × 20250428) — not submitted
